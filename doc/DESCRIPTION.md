Self-hosted any-sync network for Anytype. Accounts are created locally in the Anytype client and stay end-to-end encrypted. The server only relays encrypted data between peers.

External ports: TCP 1001-1006, UDP 1011-1016. Import `/opt/any-sync/etc/client.yml` in the Anytype client to join this network.

This is an unofficial packaging. The Anytype client may have license restrictions on commercial use; check upstream terms before deploying for an organization.
