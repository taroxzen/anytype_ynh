# 🔐 Security Policy / Güvenlik Politikası

Thanks for helping keep this project safe.  
Bu projeyi güvenli tutmaya yardım ettiğin için teşekkürler.

| 🛡️ | Bilgi / Info |
|---|---|
| ✅ | Supported versions / Desteklenen sürümler: `0.13.x` |
| 🔒 | Private reporting available / Özel bildirim aktif |
| ⏱️ | Response target / Yanıt hedefi: 7 days / 7 gün |
| 🤖 | AI-assisted project / AI destekli proje |

## 🇹🇷 Güvenlik açığı bildirme

Lütfen açığı **herkese açık bir Issue olarak değil**, GitHub'ın özel bildirim kanalıyla ilet:

👉 **https://github.com/taroxzen/anytype_ynh/security/advisories/new**

Şunları ekle:

| Bilgi | Açıklama |
|---|---|
| 🔍 | Etkilenen sürüm ve dosya |
| 🧪 | Yeniden üretme adımları |
| 💥 | Olası etki |
| 🛠️ | Önerilen düzeltme (varsa) |

⚠️ Düzeltme yayınlanana kadar açığı herkese açık paylaşma.

## 🇬🇧 Reporting a vulnerability

Please report vulnerabilities privately via GitHub Security Advisories:

👉 **https://github.com/taroxzen/anytype_ynh/security/advisories/new**

Include the affected version, reproduction steps, impact, and a suggested fix if you have one. Please do not open a public issue until a fix is released.

## 📦 Scope / Kapsam

| Kapsam | Durum |
|---|---|
| Bu YunoHost paketinin script'leri | ✅ Kapsam içinde |
| Upstream `any-sync-dockercompose` | ❌ Kendi reposuna bildir |
| Anytype istemcisi | ❌ AnyType'a bildir |
| Sunucu yapılandırması / firewall | ⚠️ Kendi sorumluluğun |

> 💡 Paket AI yardımıyla hazırlandı. Kritik ortamlarda kullanmadan önce script'leri gözden geçir.
